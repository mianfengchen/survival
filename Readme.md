# 花园幸存者

基于文档需求搭建的浏览器端 2D 生存割草原型。当前仓库已经包含可运行的游戏框架、基础玩法闭环、技能库扩展，以及重新分类后的设计文档。

## 当前实现

- 独立主菜单、天赋成长、图鉴总览、全屏战斗界面、结算界面
- 开始菜单可输入 1 到 10 的困难等级，并实时预览强度摘要
- 15 分钟生存关卡与最终 Boss 刷新逻辑
- 战斗地图扩展为原始尺寸的 9 倍，并由相机跟随角色移动
- 自动战斗、经验掉落、升级三选一、技能专属成长
- 局内基础成长项、局外天赋成长、技能工坊与专属工坊
- 图鉴支持滚动浏览，并可禁用已购买的专属成长
- 图鉴记录与浏览器本地持久化

## 快速开始

1. 直接在浏览器打开 `index.html`
2. 在菜单中确认困难等级，再点击“开始冒险”进入全屏游戏界面
3. 使用 `W A S D` 或方向键移动，`Space` 闪现，`Esc` 暂停
4. 局后获得的金币可用于“天赋成长”以及购买新技能和专属

## 项目结构

- `index.html`：界面容器与菜单结构
- `styles/app.css`：整体视觉与响应式布局
- `src/data.js`：怪物、技能、成长项、天赋等静态数据
- `src/game.js`：战斗循环、实体更新、碰撞与结算
- `src/main.js`：界面交互、面板渲染、持久化接入
- `src/storage.js`：本地存档读写

## 文档分类

- `docs/game-overview.md`：产品定位、场景与整体体验
- `docs/systems.md`：战斗、成长、图鉴、持久化等系统设计
- `docs/skills.md`：技能库、专属成长、成长项整理
- `docs/roadmap.md`：多角色、宠物、装备等后续扩展路线

## 已补充的技能

- 飞剑术：初始技能，直线发射剑型投射物，初始自带一层“虹光穿透”专属
- 向日脉冲：中近距离范围波纹
- 泡泡轰鸣：延迟爆炸与裂变型技能
- 花瓣回旋：围绕角色的持续切割技能
- 荆棘飞簇：朝最近敌人扇形射出成组荆棘刺
- 露水花圃：在敌群脚下生成持续伤害与减速的花圃区域
- 雷芽裁决：短延迟锁定敌人位置并降下落雷
- 蘑菇伏雷：在角色周围布置会自动引爆的蘑菇地雷

## 当前版本重点

- 开局只有飞剑术会进入升级池，其他技能需要先在菜单中的技能工坊购买
- 购买技能会附带一个基础专属解锁，其余专属可在专属工坊单独购买
- 飞剑术的“虹光穿透”当前最高为 3 级
- 飞剑术新增“亮闪闪”“闪亮亮”专属，“巨刃奇袭”拥有无限射程
- 最终 Boss“黄昏收割者”已强化为超巨体型并带有弹幕攻击
