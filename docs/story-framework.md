# 故事框架（草案 v2）

本文件是**结构性骨架**，不是剧本。职责：为「四方力量 → 三次选择 → 四条结局 → 终局与使者战」
提供可落地的因果关系，并为地图分支、景观、赐福、混合 Boss 提供设计依据。

## 使用约束

1. **不写与地图拓扑一一对应的线性剧情。** 分支主题各自独立成立，任意顺序推进都读得通。
   地图结构可以随时改，不会导致剧情对不上。
2. **叙事随内容生长。** 投入集中在环境叙事：分支主题、景观 lore、赐福解锁 flavor、Boss 档案。
   不做必须按序阅读的主线章节。
3. **不必立即写入游戏。** 当前只需定下阵营、选择点与结局条件，供第 3、4 阶段取舍时参照。
4. 复用既有素材；`害虫星球` 本阶段**不做**，仅作为各结局的统一后续钩子。
5. 已废弃的设定：**花心**（地图结构会变，不再需要"最后一处据点"）、
   **轮回 / 终局 Boss 是另一座花园的镜像**。

## 四方力量

| 阵营 | 立场 | 机制特征（用于设计 Boss 与分支） | 素材状况 |
| --- | --- | --- | --- |
| **植物花园** | 主角方，被侵略者 | 共生、连接、嵌合、增益链 | 充足：37 技能、36 角色、12 景观、36 区域主题 |
| **害虫星球** | 侵略者，主线敌人 | 数量、繁殖、分裂、密度压迫 | 充足：既有虫群、`裂群` / `潮汐` 波次 |
| **异化深渊** | 第三方，诱惑者 | 腐蚀、增生、不稳定、以缺陷换强度 | 需新建（外来者，不依赖既有素材） |
| **神化圣堂** | 第四方，诱惑者 | 秩序、光、审判、护盾与无敌窗、规则化弹幕 | 需新建（同上） |

异化与神化互为对手，但在一件事上一致：**不允许出现超越它们的力量**。
这是融合路线会被双方联合讨伐的原因。

## 一页前提

虫星的陨群穿过云层，害虫星球的侵略开始了。

花园打不过。花朵、植物、益虫守卫一支支失守，常规的抵抗已经证明无效。
于是花园里的大家做了最后一件事：**把各自剩下的力量全部凝聚起来，送出一个载体**——
一只小精灵。

它不是花园派出的士兵，它是花园**所有人剩下的部分**。
这就是为什么它能逐步使用别人的技能与特性：那些力量本来就在它身体里，
只是一次用不出来，需要随着战线推进一点点重新醒过来。

而在抵抗的过程中，花园撞见了另外两样东西。

**异化深渊**从被污染的土地下渗上来。它不要求忠诚，只提供一件事：
把污染当工具用，变强没有上限，代价写在身上——用得越久，你越不像原来的你。

**神化圣堂**从云层之上降下。它承诺秩序与不朽，条件是接受它的形状：
你会变得完美，但从此由它定义什么是完美。

小精灵可以都不要，只靠花园自己的力量打完这场仗。也可以伸手。

主线的终点是**虫王**——但要说清楚它是什么：
它只是害虫星球众多远征军部队中的**一支**的统帅。
打赢它意味着这次侵略被打断，不意味着害虫星球被解决；那颗星球上还有远比它强的东西。

所以真正衡量你选了什么的，不是虫王，而是打完虫王之后来找你的人。

## 精灵与赐福

- 小精灵 = 花园集体力量的载体（替代原「花心唤醒最后一只精灵」的设定）。
- 36 位角色的力量**本来就在小精灵体内**，但一次无法全部调用。
- 解放区域 → 对应的那份力量重新醒来 → 获得该角色的赐福（技能 / 特性）。
- 叙事收益：解锁不需要"又遇到一位幸存者"的重复桥段；
  花园众人处于沉眠而非死亡，为花园结局保留了回归的余地。

## 主线与三次选择

```
侵略开始 → 花园抵抗 → 推进区域（接触异化 / 神化 / 融合）
                              │
                   ┌──────────┼──────────┬──────────┐
                 不选        异化        神化        融合
                   │          │          │          │
                   └────── 击败虫王 ─────┴──────────┘
                              │
          ┌───────────────────┼───────────────────┬──────────────┐
      （无后续）         神化圣堂讨伐        异化深渊讨伐     双方联合讨伐
          │                   │                   │              │
    花园结局·存续      击败神化使者         击败异化使者     击败双使者
      （隐藏威胁）            │                   │              │
                        异化阵营结局        神化阵营结局    花园结局·新生
```

三次选择不是对话选项，而是**成长分支的投入**：你点了哪条线的节点，就是选了哪一方。

## 四条结局

| 结局 | 条件 | 终局内容 | 相对难度 |
| --- | --- | --- | --- |
| **花园结局·存续** | 未投入任何分支，击败虫王 | 侵略被击退，花园靠自己撑住了。深渊与圣堂都没出手——因为不需要出手。隐藏威胁留存 | 基准 |
| **异化阵营结局** | 异化占优 → 击败虫王触发隐藏结局 → 神化圣堂讨伐 → 击败神化使者 | 花园赢了，但赢的东西已经属于深渊。圣堂的审判被打退，秩序一方从此视花园为污染源 | 高 |
| **神化阵营结局** | 神化占优 → 击败虫王触发隐藏结局 → 异化深渊讨伐 → 击败异化使者 | 花园被纳入圣堂的秩序，永不枯萎也不再自行生长。深渊的侵蚀被挡在外面 | 高 |
| **花园结局·新生** | 融合占优 → 击败虫王触发隐藏结局 → 双方联合讨伐 → 击败双使者 | 花园没有借任何一方的力量就超过了双方。深渊与圣堂联手都没能按住它。众人苏醒，花园自主 | 最高 |

设计意图：

- 四条结局不分好坏，分**代价与独立性**。
- 难度天然成阶梯（存续 < 阵营结局 < 新生），与「难度阶梯」长尾目标自然合流。
- 「新生」是最难也最完整的一条，正好对应融合在系统上也是最强的成长轴
  （见 `design-notes.md` 第 4 阶段）。
- 四条结局都收束到 `害虫星球` 的后续钩子，但本阶段都只留一句话，不展开。

## 终局与使者战

**虫王**：害虫星球众多远征军部队中**一支**的统帅，主线终点。
打赢代表这次侵略被打断，而非害虫星球被解决——该星球仍有远强于它的存在，留作后续。
因此虫王不是强度上限，它是"主线"的上限。

**使者战**：击败虫王后触发隐藏结局的内容，才是真正的强度上限。

- 神化使者：秩序侧，护盾 / 无敌窗 / 规则化弹幕 / 审判点位。
- 异化使者：腐蚀侧，增生 / 变形 / 持续污染 / 以玩家强度为养料。

### 双使者战（融合路线）三阶段

融合路线要同时面对两位使者。两方从"互不配合"逐步走向"被迫联手"，
层层递进地印证融合路线的主题：**连接比各自更强——包括敌人那边的连接。**

| 阶段 | 形态 | 机制重点 |
| --- | --- | --- |
| 一 | **轮流上场** | 单体应对，分别学习两套机制；交接处是节奏窗口 |
| 二 | **同场但互相干扰** | 两方技能会**互相抵消**。玩家可主动走位诱导对撞，把敌人的冲突变成自己的输出窗口 |
| 三 | **联手，释放联合技** | 两方终于协同，出现只有合流才能放出的联合技；压力最高，也是全局强度天花板 |

阶段一与阶段二的顺序可互换（先同场混战、再被分开各自施压，亦成立）。实装时择一即可。

设计意图：阶段二是整场战斗的识别点——**敌人的不协调是可被玩家利用的资源**，
而阶段三把这份优势收走，逼玩家用自己的"连接"去对抗对方的"连接"。

## 三条路线的本体表现

三条路线都会**反作用到角色本体**，随进程加深。这是分支最直观的反馈，也是取舍的具象化。

| 路线 | 外观走向 | 读起来是 |
| --- | --- | --- |
| **异化** | 逐步被侵蚀：增生、结晶、轮廓崩坏，越深越不像原来的小精灵 | 变强了，但在失去自己 |
| **神化** | 逐步被规范：光环、几何化、对称化，越深越不像活物 | 变完美了，但不再是活的 |
| **融合** | 逐步**变强、变好看**：形态更完整、更有光彩，可少量融入其他角色特征（**不可突兀**，整体仍是小精灵） | 这是花园自己长出来的样子 |

融合是完美结局路线，本质是**植物花园自身力量的成长**，因此不能有"代价感"的外观。
其他角色特征的融入要克制——点缀级别，呼应"众人凝聚而成"的设定，
而不是拼贴成一个四不像。

### 异化 / 神化的机制代价

**已确认：带机制代价，且与技能强化成对出现。**
每一级本体异化 / 神化都是一笔交易，不是单纯的变强或变弱：

- 形式：**技能强化 + 机制代价**同时生效。
- 代价设计原则：**"换一种玩法"而不是"单纯变弱"**。
  例：异化换来更高伤害与增生效果，代价是受到的治疗降低 / 自身持续掉血；
  神化换来护盾与稳定性，代价是移动或转向受限、必须按节奏行动。
- 代价必须**可被构筑消化**——玩家应该有办法围绕它去 build，而不是只能忍受它。
- 随进程加深，但不做线性叠加惩罚；每一级的交易都要能被单独评估。

### 技能侧的两条获取路径

| 路径 | 范围 | 作用 |
| --- | --- | --- |
| 直接异化 / 神化 | 局外成长分支，永久 | 确定性投入，决定结局归属 |
| 异化结晶 / 神化圣痕 | **局内**掉落与拾取，仅本局有效 | 保留每局变量；可临时体验另一侧，但不改变结局归属 |

第二条路径很重要：它正是「局外决定带什么、局内决定怎么长」这一分工的落点，
使分支系统不会把局内变量抽空。

## 混合 Boss 的设计语法

既有 Boss 造型是花 / 藤 / 灯 / 蛾（`BOSS_KIN_FAMILIES` 十支族系），
这套美术资产可以通过一个设定直接复用并支持混合类型：

> **Boss 原本都是花园自己的守卫血脉，被三方力量各自重塑。**

于是混合类型有了明确语法，也解释了为什么敌人看起来像植物：

| 混合类型 | 来源 | 机制重点 |
| --- | --- | --- |
| 害虫类 | 被虫群寄生 / 改写 | 召唤、分裂、繁殖、密度 |
| 异化类 | 被深渊腐蚀 | 变形、增生、污染地面、受击后强化 |
| 神化类 | 被圣堂加冠 | 护盾、相位、无敌窗、规则化弹幕 |

同一族系可以出现三种混合版本，内容量按"族系 × 混合类型"扩张，而不是重画 Boss。

## 主题轴

分支地图与景观挂在这几条轴上取主题，不规定顺序，也不要求用满。

| 轴 | 两端 | 可挂载素材 |
| --- | --- | --- |
| 昼 / 夜 | 日照、观测 ↔ 月光、灯火、蚀影 | 日晷花坛、星泉井；月鳞、虚灯、蚀瓣族系 |
| 生长 / 腐败 | 萌发、授粉 ↔ 孢化、消解 | 授粉回廊、孢风塔；芽庭、菌幕族系 |
| 流动 / 停滞 | 风、潮、迁移 ↔ 时间、封存、琥珀 | 风拱廊、琥珀凉亭；风裁、钟藤族系 |
| 秩序 / 野性 | 庭园、规划、围墙 ↔ 蔓生、失控、荒化 | 常春门、蕨影迷宫；棱冠、暮割族系 |

注：「秩序 / 野性」轴与神化 / 异化的对立同向，可用于把两方的渗透区域在地图上区分开。

## 教学关：众愿苗圃

起始区域（`region-1`）已更名为**众愿苗圃**，替代原「最后的花心」。
它是众人凝聚出小精灵的地方，也是防线尚未被击穿的最后一片土地。

教学关**不再复用战役的波次骨架**。此前它套用压缩版战役结构，结果是
第 2 波固定为猎杀（3 只精英）、第 3 波固定抽自高压池（潮汐 / 裂群 / 突袭），
随后立刻刷 Boss——而玩家此时只有 1–2 个技能、几乎没有成长项。
更糟的是击杀目标沿用战役数值：第 1 波要求 55 杀，而该波总共只刷出约 43 只，**目标不可能达成**。

现在教学关是一套**固定、确定性**的计划（教学关每次都应该一样，否则无法教学）：

| 波次 | 类型 | 教什么 | 目标 |
| --- | --- | --- | --- |
| 1 | 歼灭 | 移动、自动开火、经验拾取、升级三选一 | 14 杀 |
| 2 | 采集 | 灵露散落各处 → 位移与镜头，并额外给经验 | 5 份灵露 |
| 3 | 歼灭 | 更密的虫群，但仍无精英、无目标风险 | 18 杀 |
| — | Boss | 收尾，可通过而非一道墙 | 击退镇守者 |

> **定目标要按「抵达量」而不是「刷出量」。** 这是本关前两版都失败的原因：
> 地图是 9 倍大，刷出的怪有很大一部分在本波结束前根本走不到玩家身边。
> 按刷出量定的目标（曾为 18 / 24）在实机里不可能完成。
> 当前目标约为实测抵达量的 **38% / 41%**，玩家原地不动也能完成。

配套调整：

- 全部波次词条固定为**平静**（玩家此时读不懂词条，随机词条只是噪音）。
- **刷怪密度上调**：教学关专用缩放为敌人 ×0.7、刷怪 **×1.6**、**Boss ×0.45**、经验 ×1.5。
  刷怪是放大而非缩小——难度 1 的基准刷怪率只有 `0.42`，本身已很稀疏，
  再下调会让整波只刷出十几只怪、击杀目标直接不可达。
  教学关要的是「**大量很弱的怪**」：有东西可打、目标可达。
- **移速与强度解耦**（`enemySpeedScale`）：`enemyScale` 原本同时作用于生命、伤害和移速，
  而难度 1 的基准移速倍率只有 `0.64`。叠上 0.7 的削弱后，最弱的露珠软虫实际只有
  **17 px/s**，在 9 倍地图上要走 40 秒以上才能接近玩家——「刷出很多怪」却「打不到几只」。
  现教学关单独把移速提到 ×1.95（实际 ≈1.25，约 47 px/s，仍不足玩家 100 px/s 的一半）。
- **刷怪点改用上下近边**：视口宽远大于高，左右边距玩家约 712px，上下边仅约 432px。
  教学关只从上下边刷新且横向偏移收窄，接近时间几近减半，且不会出现凭空出现的穿帮。
  战役仍使用四边。
- **密度保持平坦**：教学关压掉战役的逐波 ramp（战役从第 2 波起每批翻倍），
  否则采集波会变成玩家此时读不懂的追逐战。递进交给 Boss。
- 保留既有的「保底提供精灵箭术升级」逻辑。

实测（模拟玩家原地不动）：抵达量第 1 波约 36 只、第 2 波约 40 只、第 3 波约 44 只；
修复前第 1 波仅约 12 只能走到身边，而目标为 18 —— 故此前无法完成。

设计原则：**教学关的每个目标都应该能达成。** 让玩家在教学里反复看到未完成的目标，
等于教他们"目标是达不到的"。

## 已确认

- **虫王 = 害虫星球众多远征军部队中一支的统帅。** 打赢只是打断本次侵略；
  该星球仍有更强的存在，留给后续章节。
- **本体异化 / 神化带机制代价**，且与技能强化成对出现（交易式，不是单向惩罚）。
- **融合为完美结局路线**，本体外观朝"更强、更好看"方向演进，可克制地融入其他角色特征。
- **双使者战分三阶段**：轮流 → 同场互相抵消 → 联手联合技（前两阶段顺序可换）。
