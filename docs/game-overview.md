# 游戏总览

## 产品定位

- 类型：2D 吸血鬼幸存者式生存割草
- 风格：阳光、可爱、轻松，但节奏持续上升
- 单局时长：15 分钟，计时结束后刷新最终 Boss，击败 Boss 后胜利

## 场景结构

- 主菜单：独立展示开始游戏、天赋成长、图鉴入口
- 战斗场景：点击开始后切入全屏游戏界面，角色移动、技能自动释放、怪物围攻、经验与升级
- 升级弹窗：每次升级从 3 项成长中选择 1 项
- 结算界面：展示生存时间、等级、击败数量、金币收益

## 地图表现

- 当前战斗地图面积为初始原型的 9 倍
- 通过相机跟随角色，让玩家在更大地图中持续向上下左右推进
- 怪物从当前视野四周进入，而不是固定只从整张地图外缘慢速靠近

## 已实现控制

- `W A S D` / 方向键：角色移动
- `Space`：闪现，受闪现次数限制并随时间恢复
- `Esc`：暂停 / 继续

## 当前框架覆盖范围

- 战斗循环
- 怪物刷怪与最终 Boss
- 技能系统与专属成长
- 局内基础成长项
- 局外天赋成长
- 图鉴记录与持久化

## 设计原则

- 先做可运行骨架，再沿着技能、角色、宠物、装备扩展
- 技能表现尽量模块化，不把数值硬编码在 UI 层
- 文档按“概览 / 系统 / 内容 / 路线图”拆分，便于继续追加内容
